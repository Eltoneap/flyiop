Teto padrão

Vale para toda perna sem ajuste próprio. Pernas onde você já definiu um teto específico (perna a perna) continuam com esse valor, sem mudança.

Alterações de teto já valem para os alertas do Telegram, a partir da próxima verificação diária. Os alertas ainda não são individualizados por usuário — com mais de uma pessoa monitorando a mesma perna, vale o menor teto entre elas.
